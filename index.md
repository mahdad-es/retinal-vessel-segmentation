# Deep Learning for Retinal Blood Vessel Segmentation

This project presents a curvelet-guided deep-learning pipeline for automatic retinal blood vessel segmentation from colour fundus images.

## Aim

The aim of this project is to segment retinal blood vessels accurately and evaluate the predicted vascular structures using both pixel-level and topology-aware metrics.

## Pipeline

1. Fundus image preprocessing  
2. Field-of-view extraction  
3. Curvelet-based feature generation  
4. U-Net-based vessel segmentation  
5. Vessel-aware training and evaluation  

## Evaluation Metrics

- Dice score
- Intersection over Union
- Sensitivity
- Specificity
- clDice
- Skeleton Dice
- Component error

## Research Relevance

This work demonstrates my experience in retinal image analysis, medical image segmentation, and clinically motivated AI pipelines.
