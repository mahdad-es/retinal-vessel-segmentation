# Retinal Blood Vessel Segmentation

Deep-learning pipeline for retinal blood vessel segmentation from colour fundus images.

## Project Overview

This project focuses on automatic retinal blood vessel segmentation from colour fundus photography. Retinal vessel segmentation is an important step in computer-aided retinal image analysis and can support quantitative assessment of vascular morphology in ophthalmic screening.

## Research Context

This work is based on my earlier research in retinal fundus image processing, including vessel segmentation and lesion analysis. The GitHub project page has been prepared to document the methodology and present the work in a reproducible format.

## Methods

The pipeline includes:

- Colour fundus image preprocessing
- Field-of-view mask extraction
- RGB and vessel-enhancing image features
- Deep-learning-based vessel segmentation
- U-Net-based segmentation architecture
- Vessel-aware training and evaluation
- Quantitative evaluation using Dice, IoU, sensitivity, specificity, clDice, and skeleton Dice

## Applications

- Retinal image analysis
- Diabetic retinopathy screening support
- Ophthalmic image segmentation
- Medical image analysis and clinical AI research
