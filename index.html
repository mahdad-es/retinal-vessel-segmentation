Deep Learning for Retinal Blood Vessel Segmentation

A curvelet-guided deep-learning pipeline for automatic retinal blood vessel segmentation from colour fundus images, combining vessel-enhancing feature extraction with a U-Net-based segmentation model and vessel-aware evaluation.

Project Overview

This project focuses on automatic retinal blood vessel segmentation from colour fundus photography. Retinal vessel segmentation is an important step in computer-aided retinal image analysis and can support quantitative assessment of vascular morphology in ophthalmic screening.

The method combines field-of-view extraction, curvelet coefficient energy representations, scale- and direction-aware vessel features, and a U-Net segmentation model to produce retinal vessel masks from fundus images.

Aim

The aim is to segment retinal blood vessels accurately and evaluate the predicted vascular structures using both pixel-level and topology-aware metrics.

Clinical and Research Relevance

Retinal vessel segmentation can support ophthalmic image analysis, diabetic retinopathy screening, vessel morphology assessment, and clinically motivated AI pipelines.

Curvelet-Guided Pipeline

  1. Colour fundus image preprocessing
  2. Field-of-view extraction
  3. Gaussian background-subtraction enhancement of the green channel
  4. Curvelet coefficient energy-map generation
  5. Scale-energy and directional-energy feature extraction
  6. U-Net-based vessel segmentation
  7. Vessel-aware training and evaluation

Model Input Features

The released model checkpoint uses RGB fundus information, field-of-view masking, curvelet scale-energy features, and directional-energy features. 

red, green, blue,
scale_energy_s1, scale_energy_s2, scale_energy_s3, scale_energy_s4, scale_energy_s5,

fov

Final checkpoint: models/ablation_rgb_fov_scale_directional_last.pt

Evaluation Metrics

  • Dice score
  • Intersection over Union
  • Sensitivity
  • Specificity
  • clDice
  • Skeleton Dice
  • Component-count error

Local Inference

A single fundus image can be processed using the following command: 

python vessel_seg.py examples/test_original.png outputs/test_vessel_mask.png \
  --model_path models/ablation_rgb_fov_scale_directional_last.pt \
  --output_prob outputs/test_probability.png \
  --output_overlay outputs/test_overlay.png \
  --device auto
